What is Onigiri Golf?

オリンピックゲームの
スコア管理に特化したアプリ

オリンピック（マイホール）は、ホールごとにピンからの距離でメダルを競い合うゴルフゲームです。Onigiri Golfはそのルールに完全準拠した、記録・集計・精算まで一気通貫のアプリです。

2〜4人に対応。1パット成功者のみ得点獲得というシンプルなルールで、18ホールを通じてポイントを競い合います。

ダイヤモンド・竿イチ権・ニアピンなどの特殊オプションも完全サポート。細かいルールもアプリが自動で計算します。

Features

かゆいところに手が届く
アプリの機能

🏅

直感的なメダル選択

タップするだけで金・銀・銅・鉄を割り当て。再タップで解除。ホール移動時は自動リセットされます。

💎

特殊オプション対応

ダイヤモンド・竿イチ権・ニアピンに完全対応。複雑な加算もアプリが自動計算します。

📱

リアルタイム共有

QRコードまたはルームコードで複数台のスマホにスコアを同期。みんなで確認できます。

💴

レート精算

18ホール終了後、レートを入力するだけで自動精算。手計算のミスから解放されます。

✏️

スコア修正

入力ミスも安心。結果画面から任意のホールに戻ってスコアを修正できます。

⚙️

ルールカスタマイズ

メダルのポイント配分や特殊オプションのON/OFFを設定画面で自由に変更できます。

How to use

3ステップで
すぐ始められる

1

プレイヤーを登録

2〜4人のプレイヤー名を入力してゲーム開始。設定は10秒以内に完了します。

2

ホールごとに記録

グリーンオン後、各プレイヤーのメダルを選択。1パット成功者のポイントが加算されます。

3

自動集計・精算

18ホール終了後、順位と合計ポイントを表示。レートを入力すれば精算額も自動計算します。

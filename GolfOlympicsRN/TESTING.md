# GolfOlympicsRN — テスト手順

React Native (Expo) Android版のセットアップ・動作確認手順。

---

## 前提条件

| ツール | バージョン | 確認コマンド |
|--------|-----------|-------------|
| Node.js | 20以上 | `node -v` |
| npm | 10以上 | `npm -v` |
| Expo Go アプリ | 最新 | Android端末にインストール |

> Android Studio / エミュレーターは不要。実機 + Expo Go で動作確認できる。

---

## セットアップ

```bash
# リポジトリルートから
cd GolfOlympicsRN
npm install
```

---

## 起動

```bash
npm run android
# または
npx expo start
```

ターミナルに QR コードが表示される。

---

## 実機での接続方法

1. Android 端末に **Expo Go**（Google Play）をインストール
2. 端末と PC を **同じ Wi-Fi** に接続
3. Expo Go アプリを開き「Scan QR code」でターミナルの QR コードを読み取る
4. アプリが自動ビルド・起動する（初回は1〜2分かかる場合あり）

> トンネル接続が必要な場合（別ネットワーク）：`npx expo start --tunnel`

## テストシナリオ

### 1. スタート画面

| 手順 | 確認内容 |
|------|---------|
| アプリ起動 | ダーク背景・「⛳ Onigiri Golf」タイトルが表示される |
| プレイヤー人数ボタン（2/3/4）をタップ | 選択人数分の名前入力欄が表示される |
| 名前を入力せずにゲーム開始 | 「Player 1」「Player 2」…のデフォルト名でゲーム開始 |
| 名前を入力してゲーム開始 | 入力した名前でゲーム開始 |
| ⚙️ アイコンをタップ | 設定画面に遷移する |

---

### 2. ホール入力画面

#### 基本操作

| 手順 | 確認内容 |
|------|---------|
| 画面表示 | ホール番号（1）・プログレスバー・プレイヤー一覧が表示される |
| 同じメダルを2人目にタップ | 1人目のメダルが外れ、2人目に移る（排他制御） |
| 選択中のメダルを再タップ | メダルが解除される |
| 「次のホールへ →」タップ | ホール2に遷移、前ホールの選択はリセットされる |
| 「← 戻る」タップ | 前ホールに戻り、保存済み選択が復元される |
| 18ホール目 | ボタンが「結果を見る 🏆」に変わる |

#### スペシャルオプション

| 手順 | 確認内容 |
|------|---------|
| 💎 ダイヤをタップ | そのプレイヤーのメダルボタンが非活性になる |
| 💎 ダイヤを再タップ | メダルボタンが復活する |
| 🚩 竿イチ権をタップ | トグルON（メダルと重複可能） |
| 🐦 バーディをタップ | 複数プレイヤーが同時にONにできる |
| 📍 ニアピンは通常は非表示 | ショートホールトグルON時のみ表示される（※未実装の場合は確認のみ） |

#### ミニスコアボード

| 手順 | 確認内容 |
|------|---------|
| メダル・オプション選択中 | 画面下部のスコアがリアルタイムで更新される |
| 金メダル選択（デフォルト4pt） | +4pt が反映される |
| 金メダル + 竿イチ権 | +4pt + 3pt = 7pt が反映される |
| ダイヤ選択 | +5pt が反映される（メダル点は0pt） |
| バーディ選択 | +3pt が加算される |

#### ゲーム中止

| 手順 | 確認内容 |
|------|---------|
| 「✕ ゲームを中止する」タップ | 確認ダイアログが表示される |
| 「キャンセル」タップ | ダイアログが閉じて入力画面に戻る |
| 「中止する」タップ | スタート画面に戻り、データがリセットされる |

---

### 3. 結果画面

| 手順 | 確認内容 |
|------|---------|
| 画面表示 | 順位・プレイヤー名・合計ポイントが高得点順に表示される |
| 同点プレイヤー | 同じ順位が表示される |
| 「ホール別点数を見る」タップ | 展開して18ホール分の内訳が表示される |
| レート入力欄に数値入力 | 精算点・精算額が自動計算される |
| プラスの精算 | 緑色で「+〇〇円」表示 |
| マイナスの精算 | 赤色で「-〇〇円」表示 |
| 「✏️ スコアを修正する」タップ | 最終ホールに戻り、← 戻るで任意ホールまで遡れる |
| 「🔄 新しいゲームを始める」タップ | スタート画面に戻り、データがリセットされる |

---

### 4. 設定画面

| 手順 | 確認内容 |
|------|---------|
| 各メダル・オプションのステッパー | ＋/－で点数を変更できる |
| 「保存して戻る」タップ | 設定が保存されてスタート画面に戻る |
| アプリ再起動後 | 変更した点数が維持されている（AsyncStorage永続化） |
| 設定を変更してゲーム開始 | 変更後のポイントでスコアが計算される |

---

## スコア計算の検証

| シナリオ | 期待値 |
|---------|--------|
| 金メダルのみ | 4pt |
| 銀メダル + 竿イチ権 | 3 + 3 = 6pt |
| ダイヤモンド + 竿イチ権 | 5pt（竿イチは無効） |
| ニアピン単独 | 2pt |
| バーディ + 銅メダル | 2 + 3 = 5pt |
| 何も選択しない | 0pt |

精算点の計算式：
```
精算点 = 自分の合計pt × (人数 - 1) - 他全員の合計ptの和
```

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| QRコードを読んでも接続できない | PCと端末が同じWi-Fiか確認。ダメなら `npx expo start --tunnel` |
| `npm install` でエラー | Node.js のバージョンを確認（`node -v`、20以上必要） |
| 画面が真っ白 | Expo Go を再起動、またはターミナルで `r` を押してリロード |
| メトロバンドラーのエラー | `npx expo start --clear` でキャッシュクリア |
